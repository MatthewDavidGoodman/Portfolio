# Technical Portfolio

Selected work across **aerospace simulation, robotics/autonomy, semiconductor research, scientific computing, and quantitative markets**.

## Featured projects

### [Aerospace 6-DoF / Orbital Simulation](./projects/aerospace-6dof/)
C++17 / Eigen simulation core with quaternion dynamics, RK4 integration, GNC, astrodynamics, SGP4/TLE handling, conjunction research and verification tooling.

### [Jetson Autonomy Simulator](./projects/jetson-autonomy-sim/)
C++ autonomy stack bridging desktop simulation and NVIDIA Jetson deployment: sensing, estimation, planning, control, V4L2/DMA-BUF, CUDA/TensorRT boundaries and embedded-Linux scaffolding.

### [LeRobot MicroFactory](./projects/lerobot-microfactory/)
Simulation-first autonomous manufacturing cell with deterministic safety projection, grasp/placement verification, recovery logic, randomized evaluation and LeRobot policy boundaries.

### [BOM-X — AI / Semiconductor Research Engine](./projects/bom-x-research/)
Interactive research terminal that maps AI/software demand into compute, semiconductor BOM demand, capacity constraints, supplier earnings and market-expectations gaps.

## Standalone research repositories

- [HyTES Cal/Val Model](https://github.com/MatthewDavidGoodman/HyTES-Cal-Val-Model) — physics-first thermal remote-sensing calibration and validation.
- [Opening Trading Boost](https://github.com/MatthewDavidGoodman/opening-trading-boost) — level-2 market-microstructure research and opening-session execution logic.

## Reproducibility

The three code-heavy recent projects have GitHub Actions checks for their portable public paths. Generated logs, large telemetry/replay files, local builds and interview-specific material are intentionally excluded.

Older Columbia coursework is organized separately in [ColumbiaWork](https://github.com/MatthewDavidGoodman/ColumbiaWork) so it does not obscure the current portfolio.
