# Technical Portfolio

Selected software, simulation, robotics, scientific-computing, and quantitative projects.

## Recent code projects

### [Aerospace 6-DoF / Orbital Simulation](./projects/aerospace-6dof/)
C++17 / Eigen / pybind11 simulation core with Python astrodynamics, orbital propagation, GNC, conjunction analysis, validation tooling, and an ArduPilot SITL path.

### [LeRobot MicroFactory](./projects/lerobot-microfactory/)
Simulation-first robot-cell project with a closed-loop controller, safety projection, grasp/placement verification, recovery logic, randomized evaluation, and LeRobot policy boundaries.

### [Jetson Autonomy Simulator](./projects/jetson-autonomy-sim/)
C++ autonomy stack designed to bridge desktop simulation to NVIDIA Jetson deployment, including sensing, estimation, planning, control, V4L2/DMA-BUF scaffolding, CUDA/TensorRT boundaries, and embedded-Linux deployment notes.
